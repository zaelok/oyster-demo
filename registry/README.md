# Registry

Versioned, hand-written entries in the shapes of `docs/PLATFORM.md`. Profiles are generated
(`results/<run>/priors.json`) and referenced, never edited here.

- `skills/`: contracts, scorers, task descriptors, corpora, candidate flows
- `executors/`: model, settings, harness, rates
- `corpora/`: source tier, date cutoff, facets, size
- `flows/`: composites instantiated from patterns
- `roles/`: objectives and policy
